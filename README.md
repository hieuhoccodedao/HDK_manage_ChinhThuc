# HDKManagement

Phần mềm quản lý việc kinh doanh của Công ty Vật liệu Xây dựng HDK.

Project được phát triển bằng **Java Swing**, **JDBC** và **MySQL** theo mô hình **MVC**, sử dụng **NetBeans Ant**.

## Chức năng chính

- Quản lý sản phẩm
- Quản lý khách hàng
- Quản lý nhà cung cấp
- Quản lý nhập hàng
- Quản lý bán hàng
- Quản lý kho
- Quản lý thu chi
- Quản lý khuyến mại
- Tính lương nhân viên
- Báo cáo thống kê
- Chatbot AI (Gemini)
- Nhật ký hệ thống

## Thư viện cần thêm

Đặt file **MySQL Connector/J** vào:

```
lib/mysql-connector-j-8.0.33.jar
```

Tải tại:

https://mvnrepository.com/artifact/mysql/mysql-connector-java/8.0.33
